## 🚀 快速开始

## 📝 贡献指南

我们欢迎您的贡献！如果您想添加新的电子书资源：

1. **Fork** 本仓库
2. 创建一个新分支 (`git checkout -b add/new-ebook`)
3. 在相应的文件夹中添加您的资源
4. 提交更改 (`git commit -m 'Add new ebook resource'`)
5. 推送到分支 (`git push origin add/new-ebook`)
6. 创建 **Pull Request**

### 提交要求
- 确保添加的内容与文件夹主题相关
- 如可能，请提供资源的描述信息
- 遵守现有的目录结构
